Understanding RGB & Alpha

  • RGB controls colour intensity.
  • Alpha controls transparency.
  • Alpha 100% = fully opaque.
  • Alpha 50% = half transparent.
  • Alpha 0% = fully transparent.

Additive Colour Mixing

  • Red + Green = Yellow
  • Red + Blue = Magenta
  • Green + Blue = Cyan
  • Red + Green + Blue = White
